# Mingming Li Academic Website

This repository hosts the static academic website for Mingming Li at [xlmmk.com](https://xlmmk.com/).

The site is intentionally lightweight: plain HTML, CSS, a profile photo, and a downloadable CV PDF. It is published with GitHub Pages from the `main` branch.

## Main Pages

- `index.html` - homepage and academic profile
- `research.html` - research agenda, appointments, and service
- `publications.html` - publications and working papers
- `project.html` - current research projects
- `teaching.html` - teaching assistant experience
- `workshops.html` - conferences and presentations
- `contact.html` - contact details and public profiles
- `Li_CV.pdf` - downloadable CV
