# Mingming Li Academic Website

Static academic website at https://xlmmk.com/, published with GitHub Pages from `main`.

## Pages

- `index.html` — profile, selected research, education, and fellowships
- `research.html` — research agenda, experience, and academic service
- `publications.html` — papers organized by theme, with explicit publication and review statuses
- `project.html` — funding periods and current or completed contributions
- `teaching.html` — teaching assistant experience
- `workshops.html` — conference and seminar presentations
- `contact.html` — professional contact details
- `cv.html` — CV download landing page for existing links
- `Mingming_Li_CV.pdf` — current downloadable CV
- `Li_CV.pdf` — identical compatibility copy for older external links

## Updating

Keep paper titles, author order, dates, and statuses aligned with the current CV. Update both PDF files to the same version and refresh the CV query version and footer date on every page. Keep formal degree names and use individual contribution dates for project roles. Published articles and manuscripts remain grouped by topic, with a visible status on every entry.

Preview locally with `python3 -m http.server 8765`, then check desktop and phone widths, navigation, DOI links, research summaries, and the PDF download before publishing.
